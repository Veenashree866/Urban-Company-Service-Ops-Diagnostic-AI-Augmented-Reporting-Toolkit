# Urban Company Service Analytics

## Project Overview

This project analyzes **Urban Company-style service bookings** to understand city-wise and category-wise business performance.

The project uses **Python, SQL, SQLite, Excel/Google Sheets, and Tableau Public** to analyze bookings, revenue, SLA breaches, and partner performance.

## Key Analysis

* **6 Cities:** Bengaluru, Mumbai, Delhi NCR, Pune, Hyderabad, Chennai
* **6 Service Categories:** AC Repair & Service, Salon for Women, Salon for Men, Deep Home Cleaning, Plumbing, Electrical Repair
* **600 Bookings** analyzed
* Revenue and booking performance analyzed by city and category
* SLA breaches identified and analyzed
* Data cleaned and validated using Python and SQL
* Interactive Tableau Public dashboard created

## Tools Used

**Python | SQLite | SQL | Excel/Google Sheets | Tableau Public**

## Outcome

The project converts service booking data into meaningful business insights to help identify **high-performing cities, service categories, revenue trends, and operational issues**.
